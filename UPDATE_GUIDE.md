# Install the Progress Over Time update (v2)

**You do not need a new website, GitHub repository, or domain.** Keep your existing GitHub Pages URL.

1. On your phone, open the **old** version of your app, go to **Progress → Export progress** and keep the downloaded JSON backup as a safety copy.
2. Download and unzip `freestyle-130-v2-progress-over-time.zip` on your computer.
3. Open your **existing GitHub repository**. Choose **Add file → Upload files** and drag the **contents of `freestyle-skill-tree`** onto the upload area (`index.html`, `style.css`, `app.js`, `data.js`, `sw.js`, `manifest.webmanifest`, `icons`, etc.). Commit the changes to the same branch that GitHub Pages publishes.
4. Wait for the GitHub Pages deployment to finish (Actions will show a successful Pages run).
5. On your phone, open your existing website while online, refresh/reopen it, and look for the new **Journey** tab. Because it works offline, you might need to close and reopen the app once more to receive the new version.
6. Your original checkmarks should remain because this update uses the same storage key and website address. The graph starts recording **from the first day you open v2**; previously mastered skills appear as your starting number, not made-up historical dates.
7. If you change domains, browsers, or phones, import your JSON backup using **Progress → Import progress**. New v2 backups contain both current skills and their dated history.

The graph tracks changes to **mastered skills**, not minutes trained. Its line can decrease when you unmark a skill or reset mastery. Back up progress occasionally because it is saved on the device rather than the cloud.
